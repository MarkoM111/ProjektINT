## Zahtjevi
- **Node.js** (LTS) i **npm**
- **Quasar CLI** (po želji): `npm install -g @quasar/cli`

## Pokretanje (dev)
```bash
# kloniraj repo
git clone https://github.com/MarkoM111/ProjektINT.git
cd ProjektINT

# uđi u frontend dio i instaliraj ovisnosti
cd frontend
npm install

# pokreni dev server (preporučeno)
npx quasar dev
# ili, ako imaš globalni CLI: quasar dev
