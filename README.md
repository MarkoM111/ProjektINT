## Opis
SPA (Quasar + Vue) s rutama: `/` (Naslovnica), `/popisNovihKnjiga`, `/popisKnjiga`.  
Na “Popis knjiga” radi tražilica (QInput + filtriranje liste).

## Pokretanje (dev)
```bash
git clone https://github.com/MarkoM111/ProjektINT.git
cd ProjektINT/frontend
npm install
npm install -g @quasar/cli
quasar dev
